# Veteriner Göz Hastalıkları — AI Teşhis Asistanı (Prototip v2)

Kedi ve köpeklerde ön segment göz hastalıklarını fotoğraftan tanıyan, yüzde
olasılık veren bir yapay zeka prototipi. Google Gemini API ile otomatik olarak
tanıyı kesinleştirmek için muayene önerileri ve tedavi yöntemleri sunar.

Bu bir geliştirme aşamasındaki prototiptir, klinik teşhis/tedavi aracı değildir.
